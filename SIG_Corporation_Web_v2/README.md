# SIG Corporation 웹사이트

최종 Figma 페이지의 녹색 톤, 육각형 사업영역, 협력 기관 로고, 특허·인증 표를 반영한 반응형 정적 웹사이트입니다. HTML/CSS/JavaScript로 구현했으며 별도 빌드나 패키지 설치가 필요하지 않습니다.

## 로컬 실행

1. ZIP을 압축 해제합니다.
2. `index.html`을 브라우저로 열면 바로 확인할 수 있습니다.
3. 로컬 서버를 사용하려면 Node.js 18 이상이 있는 환경에서 `start-local.cmd`를 실행하거나, 폴더에서 `npm start`를 실행합니다.
4. 주소는 `http://127.0.0.1:4173`입니다. 서버 종료는 터미널에서 `Ctrl+C`를 누릅니다.

사진과 웹폰트는 폴더에 포함했습니다. 지도, 외부 기사 원문, 문의 페이지 연결에는 인터넷이 필요합니다. JavaScript를 활성화해야 전체 콘텐츠와 인터랙션이 표시됩니다.

## GitHub Pages 올리기

1. GitHub 저장소를 만들고 **ZIP 안의 파일과 assets 폴더**를 저장소 최상위에 업로드합니다. ZIP 자체만 업로드하면 웹페이지가 표시되지 않습니다.
2. `Settings → Pages → Build and deployment → Deploy from a branch`를 선택합니다.
3. Branch는 `main`, 폴더는 `/(root)`로 지정하고 저장합니다.
4. 배포 완료 후 표시되는 주소로 접속합니다. 모든 내부 경로는 상대 경로로 구성해 저장소 하위 주소에서도 동작합니다.

실제 GitHub 업로드·공개 배포는 수행하지 않은 로컬 납품본입니다. API 키나 서버 환경변수는 필요하지 않습니다.

## 파일 구성 / 수정 위치

- `index.html`: 메인 페이지, 특허·인증, 연락처 및 지도
- `news.html`: 게시물 상세 화면 공통 템플릿
- `styles.css`: 색상·타이포·레이아웃·반응형·모션
- `content.js`: 사업영역, 연혁, 뉴스 데이터
- `app.js`: 슬라이더, 메뉴, 연혁 스크롤, 뉴스 필터, 상세 화면
- `assets/`: Figma 원본 자산, 시니허그 제품 이미지, 기사 사진, 로컬 웹폰트
- `asset-sources.json`, `SOURCES.md`: 자료 출처 및 편집 기준
- `server.mjs`, `start-local.cmd`: 선택 사항인 로컬 미리보기 서버

## 적용한 동작

- 3개 메인 슬라이드, 이전·다음, 선택형 자동 재생, 키보드 좌우 이동
- 8개 육각형 사업영역과 상세 다이얼로그
- 연도 클릭 이동, 구간별 큰 연도의 CSS sticky 전환, 진행선 채움 (왼쪽 이미지 제거)
- 모바일 연도 메뉴, 모바일 햄버거 메뉴, 터치 가능한 컨트롤
- 기업 소식 / 언론 보도 필터, 6개 상세 화면, 실제 기사 5건의 원문 연결
- 본사와 기업부설연구소의 Google 지도 삽입 + 네이버 지도 바로가기
- 키보드 포커스, 건너뛰기 링크, 이미지 대체 텍스트, 모션 감소 설정 대응

## 콘텐츠 관리

- 예시 이메일과 전화번호는 제거하고 공식 시니허그 문의 페이지에 연결했습니다. 확정된 연락처를 받은 후 `index.html`에서 교체할 수 있습니다.
- 연혁의 완료 / 진행 중 / 예정 상태를 구분했습니다. 연혁의 2025년 8월 투자 유치와 11월 보도 날짜는 서로 다른 정보이므로 각각 유지했습니다.
- 현재 특허·인증·상표 목록은 사용자가 수정한 최종 Figma에 있는 내용을 반영했습니다. 명칭이 확인되지 않은 추가 출원특허를 임의로 작성하지 않았습니다.
- 상표의 상품류 설명은 출원 분야 요약이며 의료기기 허가를 의미하지 않습니다.
- `content.js`의 뉴스 항목을 추가하면 목록·상세 화면에 자동 반영됩니다. 뉴스는 RSS 자동 수집이 아닌 편집형 콘텐츠입니다.
- 기사 상세에는 원문 전체 대신 직접 작성한 요약과 출처 링크를 넣었습니다. 기사 대표 이미지는 해당 보도 페이지의 OG 이미지입니다. 공개 운영 전 기사 이미지의 재사용 권한을 확인해 주세요.
- 연혁은 이미지 없이 연도와 내용으로 구성했습니다. 스크롤 강제 이동이나 휠 이벤트 차단을 사용하지 않습니다.

## 인터랙션 보강

- 원본 5px 녹색 그라데이션 육각 테두리 복원
- HAII 사이트의 fade-in-up 흐름을 참고한 제목·본문·카드 순차 등장
- 기술 배너 배경 확대 해제 효과 및 제목 상승 등장
- 특허·인증·상표 표 행의 순차 등장과 호버 강조
- 연혁 이미지를 삭제하고 CSS sticky로 연도를 자연스럽게 넘기는 구조로 변경
- 기본 마우스/터치 스크롤을 유지하며, 연도 클릭에만 브라우저 기본 smooth 이동 사용
- 모션 감소 설정에서는 등장·이동 효과 제거

검증: DOM 기반 동작 검사 15개 통과(초기화, 슬라이드, 뉴스 필터, 기사 상세, 모바일 메뉴, 등장 효과 등록 등), JavaScript 문법, 내부 파일 및 이미지/폰트 32개 HTTP 응답, 로고 10개 렌더링, PC 연혁 배치 및 연도 클릭 이동 확인. 최종 수정 후 추가 브라우저 검사는 자동화 환경의 URL 확인 오류로 중단되어 모바일 실기기 및 전체 동작 검증은 완료하지 못했습니다.
