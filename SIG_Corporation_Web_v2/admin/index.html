홈페이지 관리자

GitHub 액세스 토큰으로 로그인합니다. 토큰은 이 브라우저에만 보관되고 GitHub 외에는 어디로도 전송되지 않습니다.

토큰은 어떻게 만드나요?
  1. GitHub에 로그인한 뒤 Settings → Developer settings → Personal access tokens → Fine-grained tokens로 이동합니다.
  2. Generate new token을 누르고, Repository access에서 Only select repositories → 이 홈페이지 저장소를 고릅니다.
  3. Permissions의 Repository permissions에서 Contents를 Read and write로 설정합니다.
  4. 만들어진 토큰(github_pat_로 시작)을 복사해 위 칸에 붙여 넣습니다.

토큰은 비밀번호와 같습니다. 다른 사람과 공유하지 말고, 공용 PC에서는 "로그인 유지"를 끄세요.
